# Phase M14.9.8.7 — Accepted Quotation to Installation Workflow Enforcement

- Only accepted quotations can create installation requests.
- A quotation can be linked to one installation request only.
- Converted quotations are hidden by default and available through the workflow filter.
- New installation request quotation options are limited to the selected customer's accepted, unconverted quotations.
- Database trigger, unique index and denormalized link protect the workflow.
